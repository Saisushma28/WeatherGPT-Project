# 🌦️ WeatherGPT

WeatherGPT is an AI-powered weather application that provides weather information, forecasts, alerts, agriculture insights, location-based weather data, and AI-powered chat features.

## ✨ Features

- 🌤️ Current weather information
- 📅 Daily and hourly forecasts
- 🚨 Weather alerts
- 🌾 Agriculture-related weather insights
- 💬 AI-powered weather chat
- 📍 Location-based weather information
- 🗺️ Weather map
- 🌍 Multi-language support
- 🎤 Voice interaction
- ⚙️ User settings

## 🛠️ Technologies Used

### Frontend
- React
- Vite
- Tailwind CSS
- JavaScript

### Backend
- Python
- FastAPI
- REST APIs
